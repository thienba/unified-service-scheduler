**Question:** What should the API answer when a staff member or manager reaches for a dealership they are not tied to (D-0001-14)? For a customer, architecture.md already says 404 so the API does not reveal that a record exists (AD-3). The same rule for staff and managers is not written down. It touches SEC-4 in security.md.

**Decided:** the recommended option. The recommendation was: C. A staff member already knows which dealerships exist (`GET /dealerships` is open to every role), so a 403 on a dealership id hides nothing, while a 404 on a record id stops anyone guessing ids. It is also easy to test.
