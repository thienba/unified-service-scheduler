**Decided:** CI runs once per pull request and once per push to `main` (no second run for a push to a pull
request's branch). Each pull request runs the checks and the Chromium end-to-end tests in 4 shards, and they block
the merge. Firefox and WebKit run on a push to `main`, every night and by hand (`workflow_dispatch`), as a warning
only. This replaces running every browser on every pull request (architecture.md 7.9 keeps Firefox and WebKit as
a warning).

Reason: the human's question about CI time and cost, and their answer ("Chromium per PR (Recommended)"), see
(the human's original message is kept in the private work repo). The public repository's Actions minutes are free; the gain is
waiting time.
