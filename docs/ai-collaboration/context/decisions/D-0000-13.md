**Every PR carries evidence the human can look at: screenshots and a video.**
- **Screen PRs (Track C):** a screenshot of every state the ticket adds (desktop 1440 px and mobile 390 px), and a short video of the flow recorded by Playwright, converted with ffmpeg to MP4 and a GIF so it plays inline in the PR.
- **Logic PRs (Track A):** a screenshot of the test run and the coverage report for the files the ticket touched, and a short video only where there is something to watch (for example the two-tab race once the API exists); otherwise the PR says "no UI yet".
- **Prototype review (Track B):** screenshots of each screen and state, with the link to the clickable prototype.

The files live in the work repo under `tasks/<id>/shots/` and `tasks/<id>/video/` and are uploaded with `gh` to the product repo's `vtc/evidence` branch (D-0000-15). Reason: the human's words ("for every PR I need you to include evidence, which can be screenshots and video"), (the human's original message is kept in the private work repo).
