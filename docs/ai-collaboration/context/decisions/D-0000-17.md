**Ask the human; do not decide alone.** While working, anything that needs confirming (a product rule, a new library, a design choice, a change of scope, a trade-off with no clear winner) is asked in chat before it is built on. Roles that find such a point write a `Q-` file with the options and a recommendation, marked `needsHuman: true`, and do not mark an option as taken; the lead brings these questions to the human together and waits for the answer before building on them. Work that does not depend on the open point carries on. This replaces VTC Lite's default "never ask, take a guess" for this project. Reason: the human's words ("if you notice anything that needs confirming, ask me, and don't decide it yourself"), (the human's original message is kept in the private work repo).
