**One shared set of design tokens** for every designer and every screen. The source of truth is `context/design/brand/` (`tokens.json` in DTCG format and `tokens.css` as a Tailwind v4 `@theme`). B0 extends it (semantic tokens such as surface, text, border, success, warning, danger, focus ring; spacing, radius, elevation, motion; light theme first) and the flow designers B1–B3 only use it, never add colours or sizes of their own (a missing token is a proposal for B4). In the product repo the scaffold ticket (A1) copies it to one file, `src/styles/tokens.css`, which is the only place colours, fonts and sizes are defined; a lint check fails the build on raw hex colours or arbitrary Tailwind values outside that file. Reason: the human's words ("There should be shared design tokens"), (the human's original message is kept in the private work repo).
