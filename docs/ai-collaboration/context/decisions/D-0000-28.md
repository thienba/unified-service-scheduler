**Question:** The customer search is `GET /customers?query=...` (architecture.md section 7.3). The search text is a name, a phone number or a registration, so it ends up in the URL: in browser history, and, on a real backend, in access logs of the server, load balancer and proxies, which AD-12 says must hold no contact details. Should the search move into a request body? It touches SEC-10 in security.md and changes the endpoint table in architecture.md, so it needs your OK.

**Decided:** the recommended option. The recommendation was: B. It is cheap now and costly to change after the screens exist, and it removes the problem instead of asking every future operator to remember a log setting.
