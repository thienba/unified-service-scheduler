**Question:** Two linked points about what the page may load. (1) `context/design/brand/tokens.css` starts with `@import url("https://fonts.googleapis.com/...")`, so every visitor's browser calls Google when the app opens. (2) A Content Security Policy (CSP) tells the browser to run only our own scripts and talk only to our own origin, which limits the damage of any script that sneaks in. Should we do either? It touches SEC-11 and SEC-15 in security.md and D-0000-12's token file.

**Decided:** the recommended option. The recommendation was: A. It is a few files and one tag, it keeps the demo working offline (a good thing for a video recording), and it lets the Playwright run prove that the app talks to no other origin. The `@import` line in `tokens.css` would be replaced by local `@font-face` rules; that is a small edit to a file owned by the design track, so it is yours to approve.
