**Question:** Do garage staff and the garage manager work for one dealership, or for all of them?

**Decided:** the recommended option. The recommendation was: A, because real dealer groups keep each site's diary apart, and it costs one list of dealership ids on the user; B is a one-line change from it (give everyone every dealership). The architecture carries a `dealershipIds` list on the signed-in user either way, so the design does not wait for this answer.

Reason: the human's answer, (the human's original message is kept in the private work repo). The options and the reasoning stay in architecture.md and directions.md.
