**Question:** Should the drop-downs, date fields and time fields use our theme instead of the browser's own pickers?

- A. Style only the closed native control. The open picker stays the browser's.
- B. Our own themed controls on React Aria Components: Select (listbox in a popover), DatePicker (calendar grid in a popover), and TimeField (24-hour, 15-minute steps). The open popup is themed too.
- C. Build them by hand with no library.

**Decided:** B.
- The design comes first, as states on the prototype with the shared tokens, and the human approves it before the build (D-0001-44 practice).
- This replaces D-0001-74 (the native time input): times now always read 24-hour.
- It removes the cause of the WebKit `<select>` message (D-0001-109). Once no native `<select>` is left, the WebKit allowance in the tests can go.
- Keyboard, screen reader, 44 px targets, phone layout and WCAG AA stay required (NFR-4, NFR-7).

Reason: the human's answer "B", (the human's original message is kept in the private work repo).
