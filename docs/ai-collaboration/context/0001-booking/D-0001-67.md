**Question:** What does a "Too soon" day tile say? The ticket (REQ-BOOK-011.AC-1) and design.md 8.7 say the tile reads "Too soon" "with the first time it opens (for example "Opens from 12:00")". The approved prototype (`customer-book.html`, D-0001-44) draws the tile as "Too soon" only. A day is "Too soon" only when the notice time leaves no start at all on it, so there is no time that day to name; a day that still has later starts (today at 10:40 with 2 hours' notice) is an open day with its count ("8 times") and its first chip is 12:45. The build follows the prototype.

- A. Keep the prototype: the tile reads "Too soon"; the first time that can still be booked shows as the first chip of an open day, and a link to a too-soon day gets the info Alert naming the next day with times (what is built).
- B. On a too-soon tile, add the next start that can be booked, on another day: "Too soon · from Thu 08:00" (longer tile text; the tile is 6rem wide on a phone, so it wraps).
- C. On today's open tile, add "Opens from 12:45" under the count when the notice time hides the morning (a second line on one tile only).

**Decided:** the recommended option. The recommendation was: A. It matches the approved prototype, and a tile with no times has no time to name; the first free start is already the first chip.
