**Question:** What makes a technician "qualified" for a service type?

- A. Each technician has a set of skills; each service type requires one skill; qualified means the skill is in the set.
- B. Certification levels (for example 1–3); each service type requires a minimum level.
- C. A per-brand certification as well as the skill (for example an EV-certified technician for EV services).

**Taken:** A, because it is the simplest model that makes "qualified" testable; B and C can be added on top of it (provisional, until the brainstorm).
