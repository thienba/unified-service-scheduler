- A. Keep it as built: a new technician or bay with the same time sends nothing. The "Change saved" text then leaves out "The customer has a new message in the outbox.", there is no "See the message" button, and there is no "Appointment moved to …" toast (the time did not move). The customer sees the new name the next time they open the appointment.
- B. A new technician (not a new bay) queues a message too, with the same words as a move or a new "changed" message. The saved text then says the customer has a new message. A backend change (outbox message kind, template words) in its own ticket.
