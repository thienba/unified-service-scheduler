**Question:** Where are branch hours configured, and what happens to booked appointments when a day's hours are cut?

- A. The manager has a screen to edit a branch's weekly hours and add date overrides; the mock API saves them. When a change leaves booked appointments outside the new hours, the change is saved, those appointments are flagged on the schedule for the manager to move (REQ-BOOK-005) and are never deleted silently.
- B. Hours live only in the seeded mock data or a config file, with no edit screen.
- C. Same as A, but a change that would strand appointments is refused until they are moved.

**Decided:** option A, confirmed (D-0001-112, Q-0001-256 A). It was taken as provisional on the first day, has been built and tested that way since, and later decisions rest on it.
