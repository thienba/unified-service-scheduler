**Question:** React Aria adds two small inline `<style>` elements of its own, which our policy (`style-src 'self'`, no 'unsafe-inline') refuses:

- A. Accept it as a known limit on iPhones and iPads, written in security.md's list of unverified claims (it was not checked on a real device).
- B. Add the hash of that exact style to `style-src` (`'sha256-...'` of the text React Aria writes). Exact, but the hash breaks when React Aria changes the text, and it loosens the policy by one style.
- C. Put `overscroll-behavior: contain` on our own sheet's scrolling area in `app.css`. This covers our sheets; React Aria's style would still be refused and its console message would still print.

**Decided:** the recommended option. The recommendation was: C, and write A's line too. Our sheet then behaves right on an iPhone, the policy stays strict, and the remaining console line is known.

Reason: the human's answer ("Cả hai đều đồng ý"), (the human's original message is kept in the private work repo).
