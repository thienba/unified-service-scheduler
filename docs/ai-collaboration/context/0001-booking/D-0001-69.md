**Question:** The approved staff pages write a flag reason as a short phrase ("Ends after Bartholomew's shift, 13:00", staff.md 5.1). The API sends the domain's own line (`flags[].reason`, from `src/domain/appointment/flag-reason.ts`): "Demo Tech Ash's shift ends at 13:00; this booking ends at 13:45." Which words do the badge, the block's accessible name and the flag panel use?

- A. Change `flagReason` in the domain to the design's phrases (shift: "Ends after {first name}'s shift, 13:00", "Starts before {first name}'s shift, 08:00", "{first name} is not working this day"; hours: "Ends after closing time, 17:30", "Starts before opening time, 08:00", "The dealership is closed this day"). Every screen (schedule, appointment, the manager's Flagged list) then shows the same short words. It is a small domain change in its own ticket, because the manager ticket reads the same field.
