**Decided:** an open list (a Select or TimeField popover, 640 px and up) is always exactly as wide as its
control. The cap at `size-dialog` (512 px) that design.md 8.27 set is removed, because on a wide form the list
ended short of the field. The calendar keeps `size-calendar`; phones keep the bottom sheet.

Reason: the human's request ("dropdown width need same width as input"), (the human's original message is kept in the private work repo).
