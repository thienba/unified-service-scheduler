**Question:** On `adjust`, what does Save do while the date or the start time is blank? Before this fix Save stayed off with "Change the time, technician or bay to save.", so the words "Choose a date." and "Choose a start time." (Q-0001-242 item 5) could only appear when the technician or bay was also changed.

- A. A blank date or start time counts as a change: Save is on, and pressing it shows "Choose a date." or "Choose a start time." under the field and in the summary, and moves focus to the first such field, as for any wrong field. Nothing is sent.
- B. Save stays off with the reason "Fix the field above to save." The field shows no message until something else makes Save available.
